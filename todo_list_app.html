如何部署至 GitHub Pages

步驟 1：建立 Repository

在 GitHub 上建立一個新的公開專案倉庫（例如命名為 todo-app）。

步驟 2：上傳此單一檔案

將此網頁程式碼完整儲存為 index.html，並上傳至您的 GitHub 倉庫的主分支（main / master）。

步驟 3：啟用 GitHub Pages

進入倉庫的 Settings > Pages，在 Build and deployment 的 Source 選擇 Deploy from a branch，Branch 選擇 main (或 master) 與 / (root)，點擊 Save。

完成！

稍等幾十秒後，GitHub 會自動產生活動網址，點擊即可隨時在線上存取與同步您的待辦清單！
